# JavaScript Debugging Playground

A frontend practice project focused on JavaScript debugging, DOM events, form validation, async error handling, payload validation, and consent-based analytics tracking.

This project was built as part of my junior frontend developer portfolio.

## Live Demo

https://sentkirali.github.io/javascript-debugging-playground/

## Features

- Calculator debug challenge
- Form validation challenge
- Async fake API request
- Loading, success, and error states
- Debug log panel
- Analytics-style event payload validation
- Custom `dataLayer` event queue
- Consent-based tracking control
- Clear dataLayer functionality
- Modular JavaScript structure

## Key Concepts Practiced

- HTML5
- CSS3
- JavaScript
- DOM manipulation
- Event listeners
- Form validation
- Async / await
- Promise handling
- Try / catch error handling
- Payload validation
- Data layer logic
- Consent logic
- Browser DevTools
- Console debugging

- Git and GitHub workflow
