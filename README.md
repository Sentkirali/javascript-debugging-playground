# JavaScript Debugging Playground

A small frontend project focused on JavaScript debugging, DOM events, form validation, async error handling, and Browser DevTools practice.

## Features

- Calculator bug fixing
- Form validation
- Async API request simulation
- Error handling with try/catch
- Debug log panel
- Payload validation
- DOM event handling

## Key concepts practiced

- JavaScript fundamentals
- DOM manipulation
- Event listeners
- Form validation
- Async/await
- Fetch API
- Error handling
- Browser DevTools
- Console debugging
- Network tab inspection
- Payload validation
